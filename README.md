# Krazy Koozies

Website for Krazy Koozies, custom foam and neoprene koozie printing from Oakland.

This repo is a static site. Open `index.html` to preview it, or turn on GitHub Pages (Settings → Pages → Deploy from branch `main`, folder `/ (root)`). The live URL will be:

https://jeanmors.github.io/krazy-koozies/

Fonts (Fredoka, Nunito, and Lilita One) load from Google Fonts.
